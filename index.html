Rest the pointer on an event bar below the first row, press N, then keep moving it by a pixel or two for a few seconds. R stops and reloads the full data set.
N stands in for a filter narrowing the result set: it replaces both stores with a single resource, then puts the full set back, over and over. It is a key rather than a button because reaching for a button would move the pointer off the bar, and the pointer staying put is the whole point.
